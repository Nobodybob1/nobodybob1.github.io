# Janko Štrkalj - Portfolio

**Live site: [nobodybob1.github.io](https://nobodybob1.github.io)**

Personal portfolio of Janko Štrkalj, a backend & software engineer from Kragujevac, Serbia, building backend systems, AI pipelines and IoT software.

The site covers:

- **Shipped work** - Neighborhood Energy Orchestrator (IoT PoC for a Dutch energy-tech client) and GRCentric (compliance-automation platform)
- **Current builds** - Riskform, GRC Assistant, Evidence Manager
- **Earlier projects** - [Haiku Clock](https://github.com/Nobodybob1/Haiku-Clock), [Music Recommendation](https://github.com/Nobodybob1/Music-Recommendation), [Travel Agency](https://github.com/Nobodybob1/Projektni-zadatak-iz-informacionih-sistema-i-baza-podataka)
- Skills, experience, education and contact

## Built with

A single static page, no frameworks and no build step.

- Plain HTML, CSS and vanilla JavaScript in one `index.html`
- [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) via Google Fonts
- Light / dark theme that follows the system setting, with a manual toggle remembered in `localStorage`
- Responsive layout and `prefers-reduced-motion` support
- Hosted on GitHub Pages

## Repository structure

```
.
├── index.html             # the whole site: markup, styles and scripts
├── Janko-Strkalj-CV.pdf   # downloadable CV
├── preview.png            # link-preview image for social sharing
└── README.md
```

## Running locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```
